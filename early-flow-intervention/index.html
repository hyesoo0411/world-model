2 · Intervention · 적용 검증

Goal 지정한 robot-flow 교정이 의도대로 적용됐는지 확인합니다.

v_bg = vθ(x_current, τ, BGb, A)
v_ref = vθ(x_current, τ, BG0, A)
v_used = v_bg + α M_robot ⊙ (v_ref − v_bg)
SAME current x · SAME action · SAME τ

Input 기존 시간별 simulator robot coverage · agentview 미래 latent 1–5 · α=1. 각 단계에서 5개 미래 latent를 동시에 교정합니다.

Output Flow는 생성 latent의 변화율입니다. Robot 영역 flow만 교체 → 공식 AB2 update. Soft 경계는 부분 교체, coverage=1인 내부는 완전 교체. RMS 계산 범위: coverage≥0.5인 로봇 위치 ×5개 미래 slot ×16 channels.

Result Early 0–11 · Middle 12–23 · Late 24–35. 마지막 step 35는 decode용 최종 평가입니다.

Result · 읽는 법 아래 RMS는 개입한 바로 그 step의 같은 현재 latent에서 교정 전·후 flow를 BG0 반사실 flow와 비교한 값입니다. 감소는 교정식에서 예상되는 결과로, 구현 검증이며 그 자체가 인과 효과의 증거는 아닙니다. 특정 구간 교정 후 마지막 step의 flow RMS를 비교한 그래프가 아닙니다. 교정 이후 생성 결과의 변화는 Section 4·5의 최종 로봇 궤적·회복률과 Section 6의 이후 latent 경로에서 평가합니다.

5 · Recovery

Goal Early 교정의 회복이 late보다 큰가?

D_BG = mean_t ‖p_BGb − p_BG0‖₂
D_int = mean_t ‖p_int − p_BG0‖₂
Recovery = 1 − D_int / (D_BG + ε)
Δ_EL = Recovery_Early − Recovery_Late
Recovery: 1 = BG0 일치 · 0 = 이득 없음 · 음수 = 악화

Input Paired task / seed / background · near-zero D_BG는 undefined.

Output 회복률은 각 case의 비율을 계산한 뒤 평균합니다. 평균·중앙값·task bootstrap95% CI. nADE = 평균 GT 위치 오차 / 영상 대각선 길이.

Result

Task별 조건 평균은 각 유효 표본, Early−Late는 공통 유효 frame·표본 기준입니다. 전체 CI는 task를 재표집합니다.
