2 · Cumulative recovery

Goal E+M 교정 후 Late를 BGb flow로 돌려도 회복이 남는가?

D_BG = ADE(T_BGb, T_BG0) · D_k = ADE(T_k, T_BG0)
Recovery(%) = 100 × (D_BG − D_k) / (D_BG + ε)
Absolute reduction ΔD = D_BG − D_k

Input 동일 task/background/seed의 네 개입에 공통으로 유효한 future frames.

Output 회복률 + 실제 px 감소 + ADE/FDE. 양수는 BG0 방향 회복, 음수는 악화. BG0는 물리 GT가 아닙니다.

점: sample별 지표의 평균 · 오차막대: task cluster bootstrap 95% CI (1,000회). 작은 baseline 차이의 비율 민감도는 아래 sensitivity에서 확인합니다. All-steps는 구현 상한 검증입니다.

3 · E+M vs M+L · matched duration

Goal 같은 24회 교정에서 시간 위치가 중요한가?

Δ = Recovery_E+M − Recovery_M+L

Input 같은 표본·유효 frame · E+M: steps0–23 · M+L: steps12–35.

각각 24회 flow 평가입니다. 공식 sampler에서 E+M은 24 updates, M+L은 23 updates + 최종 clean 평가1회이며, noise 구간도 다릅니다.

Output Paired 차이와 task-bootstrap CI. CI가 0을 포함하면 우위를 확정하지 않습니다.

8 · Flow inside and outside the robot mask

Goal 배경이 만든 flow 차이가 robot mask 밖에도 존재하는가?

RMS_region(v_b − v_0) · 1 − cos_region(v_b, v_0)

Input 동일 초기 x, step0 · 전체 tensor / 기존 robot mask / 미래 mask 밖.

Output 영역별 크기·방향 차이. Mask 밖은 다른 view도 포함하며 순수 배경 영역과 같지 않습니다.

영역별 RMS는 원소당 크기입니다. 위치별 기여의 인과적 우위를 이 값만으로 판단하지 않습니다.

9 · Validation / limitations

Goal 관측 전환 없이 flow 개입만 적용됐는지 확인합니다.

Active: v_used == v_0 (entire tensor)
Inactive: v_used == v_b
Same-background no-op: identical latent, frames, tracks

Input 검증 pilot + 모든 rollout의 hash·timestep 검사.

Output Exact assertions · tracker QC · CPU RAM / GPU VRAM 기록.

관측-frame latent의 공식 BGb 고정은 유지됩니다. All-steps의 미래 clean latent가 같아도 VAE의 시간적 혼합과 추적 때문에 BG0 영상/궤적에 잔여 차이가 생길 수 있습니다. Full-spatial은 appearance·object·background flow까지 바꾸므로 순수한 “action flow” 개입이 아닙니다.
