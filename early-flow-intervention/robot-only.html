10 · Stage-wise Robot-Flow Intervention

Goal 배경이 만든 robot-flow 차이 자체를 교정하면 최종 로봇 궤적이 BG0 방향으로 회복되는가?

Input · Observation 모든 개입에서 BGb → BGb → BGb 고정. 물리 상태·action·초기 noise·scheduler도 동일합니다.

Flow 개입Early 0–11Middle 12–23Late 24–35
EarlyBG0 robot-flowBGb flowBGb flow
MiddleBGb flowBG0 robot-flowBGb flow
LateBGb flowBGb flowBG0 robot-flow
FullBG0 robot-flowBG0 robot-flowBG0 robot-flow

Formula

v_b = vθ(x_current, τ, I_BGb, A)
v_0 = vθ(x_current, τ, I_BG0, A)
v_used = (1 − M_robot) v_b + M_robot v_0
SAME current x · SAME τ · SAME A
Outside active window: v_used = v_b

Input · Mask 기존 시간별 simulator soft robot coverage · agentview 미래 latent L1–L5. BG0는 현재 latent의 반사실 flow 평가에만 사용합니다. 독립 BG0 rollout의 flow를 복사하지 않습니다. Soft 경계는 부분 교체입니다.

D_BG = ADE(p_BGb, p_BG0) · D_int = ADE(p_int, p_BG0)
Recovery(%) = 100 × (D_BG − D_int) / (D_BG + ε)
ΔD = D_BG − D_int
FlowCorrection = 1 − RMS_robot(v_used − v_0) / (RMS_robot(v_b − v_0) + ε)
D_dir = 1 − cos_robot(v_b, v_0)

Output 최종 궤적의 ADE/FDE to BG0 · Recovery % · ΔD(px) · GT ADE/FDE · flow 교정률. Flow RMS 감소는 적용 검증이며, 이후 최종 궤적 변화가 인과 실험의 결과입니다.

Result

Output · 통계 네 robot 개입의 동일 유효 표본·frame으로 비교합니다. CI는 6 task cluster를 1000회 재표집했습니다. 비율은 sample별로 계산한 뒤 평균합니다. GT 지표는 별도 visibility 기준입니다.

Result · 대조군

Far-background control은 robot 주변 두 latent cell을 제외한 영역만 교정합니다. Mask 크기·개입량이 달라 완전히 동일한 강도의 공간 비교는 아닙니다.

Result · Flow 방향 원래 common-BG0-latent 경로의 방향 차이와 최종 recovery를 비교합니다. 개입 경로에서 측정한 방향 차이는 CSV에 별도 기록했습니다. 아래 상관은 인과 매개 효과를 증명하지 않습니다.
